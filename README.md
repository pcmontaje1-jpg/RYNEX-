# RYNEX-# Rynex PC Store

A modern PC components and pre-built PC store with cart and checkout (demo payment).

## How to run
1. Download all files into one folder.
2. Open `index.html` in your browser.

## Structure
- `index.html` – markup
- `styles.css` – all styles
- `script.js` – product data, cart logic, modals, checkout

## Payment
The payment form is currently for demonstration only. To accept real payments, integrate with Stripe, WayForPay, LiqPay, or another gateway and add server-side code.
